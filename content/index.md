# Yago Tomaszewski

<div class="sf-role">data scientist & systems architect · Lisbon, PT</div>

---

I build things that work at scale — from optimisation models and computer vision pipelines to the API layers that carry real transaction volume. The through-line is math: the conviction that if you model the problem precisely enough, reality has no choice but to follow.

I am drawn to projects where the components are unfamiliar. Recently that has pulled me toward hardware — running my own server, pairing compute with AI work, thinking ahead about what the next upgrade unlocks. Control matters, but so does the pleasure of a system built exactly to spec.

Off the screen: jiu jitsu, kali eskrima, bouldering, travelling. History and philosophy as operating systems.
